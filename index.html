Study hours, physical activity, nightly sleep and self-reported stress level.

About MindScope

MindScope is a portfolio project that connects a trained regression model, served through FastAPI, to a browser interface. Each submission is sent to the model and the number it returns is shown as-is. It is a learning demonstration, not a screening tool.

MindScope

A machine learning demonstration that estimates a student mental-health-related score from submitted inputs.

Disclaimer: the prediction is an experimental ML estimate. It is not a clinical diagnosis and does not replace a professional mental-health assessment. If you are worried about your well-being, please talk to a qualified professional.
